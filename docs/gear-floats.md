## ⚠️ Пастка специфікацій
Розрізняти: *Item Weight* (власна вага тіла) vs **Loading Lead Weight = вантажопідйомність** (це число для підбору). Якщо вказано «плавучість + вага» — віднімати.

## Корективи (підбір ваги)
- мілина <1.5 м, штиль → 1.0 г
- глибина 2–3 м → 1.5 г
- вітер → +0.3–0.5 г
- «оптична»/потовщена антена = краще видно, гірша делікатність; для ~8 м не треба

## Переглянуті серії (кандидати, НЕ куплено)
**Критерії вибору нового:** тонке веретено; довга тонка суцільна антена; карбоновий кіль; довжина 30–37 см. Вагу — за «Корективами» вище.
Куплено лише **XM-02 / XM-03** (сторінки вище) + балса + FW-06. Решта — розглянуті на AliExpress:
- **XL / XM** — найделікатніші, тонка антена 1.3–1.6 мм: XL-01 (0.9), XM-01 (1.0), XL-02 (1.2), XL-03 (1.4). Серія суто легка, «важкого» нема.
- **S-203** ✅ ідеальна (size1 1.2 / size2 1.5 / size3 1.8), але НЕ в наявності
- **Wuyazi WF-02** ✅ size1 (1.6) + size2 (1.9), тонкий хвіст 2.0 мм
- **SZ-02** (1.2) + SZ-05 (1.7) ✅, але антена роздута до 7 мм
- WA-серія — майже все важке, гірша
- HF-101 (1.4) / HF-102 (2.0) — herabunafishing, робочі
- KENYU UV (LED/нічні), YW, N-01/N-03 двосторонні — koifish, не в основний діапазон або нішеві

## Рекомендований підсумок
Пара: легкий-основний (XM-02 1.3 або XM-03 1.5) ✅ **є** + важчий 1.8–2.0 з іншої серії (Wuyazi WF-02 size2) — ще нема. Балса (2.91 г) + FW-06 (2.6 г) закривають «вітер/глибина».

## ⚠️ Прогалина: немає поплавця під <1 м
Найлегший наявний — **XM-02 (вантажопідйомність 1.3 г, ~1–1.5 м)**. Під **делікатну близьку ловлю <1 м** (обережний карась) бракує легшого.
**Цільові характеристики:** вантажопідйомність **~0.6–1.0 г** (за вітру +0.3); коротша загальна довжина (~20–30 см) + коротший карбоновий кіль; мале тонке тіло (повільне падіння); тонка суцільна антена 1.0–1.3 мм; легкий матеріал (балса/очерет/EVA).
**Найпростіше:** з тієї ж серії, легші — **XL-01 (0.9 г)** або **XM-01 (1.0 г)** (див. «Переглянуті серії») → [shopping](shopping.md).
