# Łowisko Kłaj (PZW Okręg Tarnów) — потенційне

> ✅ **Потенційне місце (переглянуто 2026-08-09).** Це вода **PZW Okręg Tarnów**, але **карта вендкарська НЕ потрібна** — достатньо **купити дозвіл** (як на [Бонарці](waters-bonarka.md)). Раніше хибно відхилив, гадаючи що потрібна карта.

Розташування на схід від Кракова, біля автостради A4. Особисто не відвідував.

- **Гео:** 49.9833361, 20.3211253 ([Google Maps](https://www.google.com/maps/place/?q=place_id:ChIJQzRGpAg7FkcRETIl221vhEc))
- **Адреса:** Kłaj, 32-015.
- **Дорога:** на схід від Кракова, **~30 км**, **біля A4** (близько, зручно їхати).
- **Тип:** вода **PZW Okręg Tarnów** — **карта НЕ потрібна**, достатньо **купити дозвіл** (день). Ціну/умови уточнити.
- **Телефон:** TBD / подзвонити.
- **Години:** **щодня 5:00–22:00**.
- **Оцінка Google:** 4.2 (16 відгуків).
- **Водойма:** жвировня (гравійний зб.) ~**1.5 га**, глибина **до 2 м**; відрізана автострадою A4, з півночі — вал від русла Раби. З 2015 облаштована під ловлю (помости, з'їзди, профільований берег); регулярно зариблюють коропом.

## Режим / ціна (дозвіл PZW Tarnów, 2026)
Карта НЕ потрібна — купується **дозвіл (zezwolenie)**, найпростіше **онлайн через e-zezwolenia PZW Tarnów**. Kłaj = **жвировня (зб.)** → діють ставки для зб-жвировень:
- **Одноразовий / окресовий:** **1 день ≈ 60 zł** · 3 дні ≈ 140 zł · 7 днів ≈ 220 zł.
- **Річний (okręgowa):** зб-жвировні **400 zł** (член) · для **нечлена річний на всі води — 1000 zł**.
- ➡️ **Для нечастих виїздів — 1-денний ~60 zł онлайн** (річний нечлену 1000 zł невигідний).
- ⚠️ Ставки окресові вказані як **членські**; окресові «без пільг» → орієнтир і для нечленів, але **точну ціну для нечлена звірити на платформі** e-zezwolenia. Правила води (1 гачок / C&R / ліміти) — уточнити на місці/сторінці PZW.

## Рибостан (дані PZW Tarnów)
- **Домінують: лин, карась, плітка, щука.** Також **лящ, короп, амур (білий), окунь, язь**.
- Місцеві повідомляють про **великих коропів/амурів** (ймовірно після повені 2010 — змішались із водами сусідніх комерційних ставів).
- ✅ **Лин + карась + лящ** — прямо мій профіль (херабуна, тісто, 1 гачок). Сильний плюс.
- ⚠️ Зариблення за старими відгуками нерівне — перевірити перед виїздом.

## Методи (за відгуками)
- **Поплавок** і **фідер/метод**.

## Локація / нотатки
- ⚠️ Близько до **автостради → шум**.
- Відгуки **змішані** (буває нерівномірно зариблено) — оцінка 4.2 нижча, ніж в [Owczarnia](waters-owczarnia.md), але **ближче** і є **карась**.

## Статус для мене
- ✅ **Потенційне (сильний кандидат)** — карта не потрібна, дозвіл **~60 zł/день онлайн** (e-zezwolenia). ~30 км, біля A4. **Лин + карась + лящ** = прямо мій профіль.
- ⏳ **Перед виїздом:** звірити ціну дозволу для нечлена на платформі; правила води (1 гачок / C&R / ліміти); свіжий стан зариблення.
