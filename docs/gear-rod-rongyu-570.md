# Rongyu «РОНЬЮ» 5.7 м

> ✅ робоча · **основна хера-вудка** (мах); тягне карпа ~40 см, бланк дуже добре працює

## Короткий опис
- **Тип:** мах (хера-вудка, без кілець); серія Rongyu, внутрішній ринок Китаю
- **Довжина:** 5.7 м
- **Матеріал:** карбон TORAY 19T
- **Стрій / вага / транспортна:** ⏳ уточнити
- **Ліміт ліски:** ⏳ уточнити
- **Роль:** **основна хера-вудка** — мах-стиль (карась/лин/лящ + короп); закриває махову роль після поломки [GOLDLITE](gear-rod-goldlite.md)
- **Статус:** ✅ куплено

## Замітки
- **Серія Rongyu:** ручка «Гусяче яйце» (ергономічна, не ковзає), конектор **360°**, комплект — запасний кінчик + неопреновий чохол.
- **Карбон 19T** — нижчий модуль, ніж 30T+40T у [2.7 м](gear-rod-rongyu-270.md) (типово для довгого бланку): параболічніший/пружніший, добре амортизує ривок.
- ✅ **Бланк дуже добре працює** (оцінка Сергія); **витягував карпів до ~40 см, можливо потягне й більше**.
- **Розподіл у парку:** Rongyu 5.7 = основний **мах/хера** (fixed line, кайф від вивідування); [Mikado 390](gear-rod-mikado-390.md) = **котушкова** під цілеспрямованого крупняка (фрикціон). Тобто силову махову роль по короткій рибі знову закрито — але для навмисного трофея в корчах лишається котушка (урок [07-01](gear-rod-goldlite.md)).
- ⏳ Уточнити: вага, стрій, транспортна довжина, ціна, ліміт ліски; фактичну довжину зміряти (правило номіналу → [gear-rods](gear-rods.md)).

## Історія використання
- **2026-08-09 · [Озеро Бонарка](waters-bonarka.md):** ранок 6:00–9:00, вітер, поплавок [балса 2.91 г](gear-float-balsa.md), гачки №14/№12. **2 лящі ~40 см (~1.0–1.3 кг) + ~6 підлящів** → [fish-log](fish-log.md).
- **Карпи до ~40 см** витягнуті на неї (дати ⏳) — бланк класно відпрацьовує, ймовірно потягне й більше.
