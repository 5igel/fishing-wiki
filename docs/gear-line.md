| Елемент | Базово | Стеля (короп) |

## Правила
1. Повідець завжди тонший за основу (~60–70%) — рветься він.
2. Основна не товще ліміту вудки (#1.5). Товще → ламається бланк, а не рветься ліска.
3. Основна — м'яка нейлонова монка (краще лягає на маху). Повідець — монка або флюр.
4. Флюр на повідець: під делікатного карася НЕ треба (жорсткий), але під трофей з тертям об рибу/траву — виправданий.
5. **Заломи вбивають лінію:** складання втроє / скручування при транспортуванні → міцність нейлону падає **до 50%**, обрив стається **посередині** (не на вузлі). Не складати; габаритне знімати → модульна оснастка зі знімною груз-секцією [technique-rigging](technique-rigging.md). Там же **запланована слабка ланка** — груз-секція з жилки на 0.02 мм тоншої за основну (рветься секція, не основна).

## 🛒 Європейський опис силової ліски (для фіз. магазину)
Що казати/шукати на польській вітрині, щоб узяти аналог #1.5:
- **Тип:** *żyłka monofilowa* (нейлон/монофіл) — **НЕ** plecionka (плетінка), **НЕ** fluorocarbon.
- **Призначення:** *spławikowa / matchowa*; бажано **тонуча — _tonąca / sinking_** (краще для маху, менше зносить вітром).
- **Діаметр (Średnica):** **0,20–0,205 мм** — ключовий параметр (= #1.5). Базова легша основа = 0,18 мм (#1.2).
- **Міцність (Wytrzymałość):** **~4,5–5,5 кг** (≈10–12 lb).
- **Характеристики:** м'яка/пластична (*miękka*), низька пам'ять; колір темний/нейтральний.
- **Намотка:** 150 м достатньо.
- **Бренди (матчева/спортивна монка ~0,20 мм):** Trabucco (T-Force XPS Match Sinking), Colmic, Milo, Maver, Sensas, Daiwa, Shimano, Mikado.
- **Під яку оснастку:** основа #1.5 (0,20) + повідець #1.0–1.2 (0,165–0,185) — див. «Силова оснастка» вище.
