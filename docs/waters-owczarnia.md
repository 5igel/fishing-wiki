# Łowisko Owczarnia (комерційне, ставки)

Приватне/комерційне ловисько на захід від Кракова. **Карти вендкарської не треба** (приватна вода). Особисто **ще не відвідував** — занесено з відкритих даних.

- **Гео:** 49.9195626, 19.2099592 ([Google Maps](https://www.google.com/maps/place/?q=place_id:ChIJRbpRMmiXFkcRS9GbdtBaCow))
- **Адреса:** Nowa Wieś, 32-651.
- **Дорога:** на захід від Кракова, **~50 км** (далеко).
- **Тип:** комерційне/приватне ловисько — **без карти вендкарської**.
- **Телефон:** +48 604 876 960.
- **Години:** Пн–Пт **8:00–20:00**, Сб–Нд **6:00–20:00**.
- **Оцінка Google:** 4.5 (149 відгуків).

## Стави / локація
- **Два стави:**
  - **Більший** — для досвідчених, **велика риба**.
  - **Менший** — для початківців.

## Рибостан
- **Переважно короп.** Риба у **дуже добрій кондиції**, **багато поклювань**.
- ⚠️ **Карась НЕ є основним видом** — під мій профіль (карась/лин/лящ на тісто) місце менш профільне.

## Статус для мене
