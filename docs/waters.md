# Водойми (Краків і околиці)

Поки загальні нотатки — деталізувати по конкретних місцях.

## Конкретні місця
- [waters-kocierz](waters-kocierz.md) — Łowisko Kocierz (платний ставок), глибина залежить від точки (~3.5 м / ~1 м), карась + лин + **короп (52 см ~3 кг)**, крупна риба, 50 zł, без зв'язку
- [waters-poddebem](waters-poddebem.md) — Łowisko «POD DĘBEM» (платне озеро), ~1–1.5 м, лящ/густера + плітка, дрібніша риба, 20 zł, легше їхати
- [waters-bobrowe](waters-bobrowe.md) — Łowisko Bobrowe Rozlewisko (комерційне, без карти), ~25 км, **2 ставки** (Sport 4 га / Duży 17 га), глибина ~2–2.5 м, карась/короп/амур (+ багато видів), оплата вхід + за рибу по кг; ✅ сподобалось, був 06-24 (спека, без улову)
- [waters-owczarnia](waters-owczarnia.md) — Łowisko Owczarnia (комерційне, без карти), ~50 км захід, переважно короп (карась не основний), запасний під коропа, не відвідував
- [waters-bonarka](waters-bonarka.md) — Озеро Бонарка (Краків), локальне; ✅ ранковий лящ (2 шт ~40 см + ~6 підлящів, 2026-08-09) на хера; режим/адмін ⏳
- [waters-klaj](waters-klaj.md) — Łowisko Kłaj / жвировня PZW Tarnów (~1.5 га, до 2 м): ✅ **потенційне** — карта НЕ потрібна, дозвіл **~60 zł/день онлайн**; ~30 км біля A4; **лин + карась + лящ** (мій профіль)
- [waters-kuterport](waters-kuterport.md) — Kuter Port (Nieznanowice), комерційне трофейне (короп), ~35 км; стани S1–S30, **дистанційний фідер**; візит 2026-08-23 (S20) = нуль (риба за ~45 м, пікер не дотягується)

## Доступ до вод PZW (для Сергія)
- ✅ **Karta wędkarska Сергію НЕ потрібна** — він **іноземець** (звільнений від державної картки, перевірено 100%). Тобто **жодного екзамену/картки** — для PZW-вод достатньо купити **дозвіл**.
- **Дозвіл на води** (składka okręgowa / zezwolenie) — купується онлайн (e-zezwolenia): **денний ~60 zł** або річний.
- **Членство PZW** — опційно, **лише заради дешевшого річного дозволу** (не через картку). Вступ у коло: деклара́ція + одноразове **wpisowe** + річна **składka ogólnozwiązkowa** (~30–110 zł ⏳ звірити).

**Що дає членство:** дешевший **річний дозвіл** — Tarnów **400 zł** (зб-жвировні, член) проти **1000 zł** (нечлен) → економія ~600 zł/рік; доступ до загальнодоступних вод PZW **по всій Польщі** (з місцевим дозволом); пільги; участь у колі/змаганнях/зарибленні.

**Кому вигідно:** членство окупається лише при **регулярній** ловлі на PZW-водах (Kłaj / Bonarka / річки). Для рідких виїздів — **денний дозвіл (~60 zł)**, без членства. Для приватних комерційних ([Kocierz](waters-kocierz.md) / [Pod Dębem](waters-poddebem.md) / [Bobrowe](waters-bobrowe.md)) — PZW **не потрібне взагалі**.

## Спостереження
- Місцеві ставки/озера: ловля з берега, дистанція коротка → потрібна 4.2+ м.
- **Закономірність «глибоко під берегом»:** ціль (лин, лящ, крупний карась) тримається на глибині майже біля берега.
  - Раніше: ділянка з глибиною ~2.5 м під берегом → трофейні лин/лящ.
  - [Łowisko Kocierz](waters-kocierz.md) (2026-06-15): за ~1 м від берега глибина ~3.5 м → лин + карась, активне клювання, крупна риба.
  - Висновок: на коротких дистанціях шукати глибину одразу під берегом; саме там трофеї, тому повідець під крупну рибу (#1.0–1.2), не делікатний.
- Глибину на робочій дистанції перевіряти самому перед ловлею (на Kocierz власник завищив: казав 5 м, реально ~3.5 м).

### Глибина vs дистанція: коли довша вудка справді потрібна (2026-06-22)
Питання: «щоб відбити дрібняк, треба кидати глибше → потрібна довша вудка?»
- **Глибину задає спуск (стопор), не довжина вудки.** На [Kocierz](waters-kocierz.md) ловив 3.5 м під самим берегом короткою Moonlight — глибина була одразу.
- **Довжина дає дистанцію, не глибину.** Довша вудка допомагає ТІЛЬКИ якщо на конкретній точці глибина росте з відстанню (полога зона), і потрібно дістати до дальшого глибшого місця.
- **Дрібняк vs трофей — це часто про точку, не про снасть.** Пологі мілкі точки (Kocierz 06-20 ~1 м далі від берега; весь Pod Dębem) = багато дрібної риби. Берегові свали (Kocierz 06-15 ~3.5 м) = трофеї.

Алгоритм рішення «чи треба 5.4»:
1. На пологій точці **проміряти глибину на макс. закиді** наявної вудки.
2. Якщо на 6–7 м уже 1.5–2 м → GOLDLITE 4.35 (✅ приїхала 2026-06-23, дистанція ~8.5–9 м) дістане, нова вудка НЕ потрібна.
3. Якщо нормальна глибина тільки за 9+ м → тоді так, 5.4 (реально 5.2, дістає ~10.5 м) виправдана **під цю точку**.
4. Дешевший хід перед покупкою: знайти глибшу берегову точку наявною снастю (як 06-15).

> Жодна поточна точка ще не показала «глибина за 9+ м» — на Kocierz глибина під берегом, на Pod Dębem скрізь мілко незалежно від дистанції (там трофеї бере фідер, бо велика риба за межами маху). Тобто проти дрібняка довжина допомагає не завжди — іноді потрібен інший спосіб (фідер) або інша точка.
> ⚠️ Не купувати 5.4 «бо так у спортсменів на відео» — у них помости, канали/водосховища, риба на дистанції. Купувати лише за результатом власного проміру.
