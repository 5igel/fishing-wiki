# Ultra-Long Balsa Wood Fishing Float (2.91 г)

> ✅ є (×3) · важчий: глибина/вітер (~2 м+)

## Короткий опис
- **Тип / форма:** довге веретено, **балса**; у наборі йшли гачки + float rest
- **Вантажопідйомність:** 2.91 г
- **Власна вага:** 1.42 г
- **Геометрія:** довжина 41 см · тіло 10 см / Ø 9.7 мм · антена 26 см / Ø 0.7–1 мм · кіль 5 см / Ø 1.7 мм
- **Глибина:** 2 м+ (і під берегом ~3.5 м)
- **Погодні умови:** вітер / брижа (важчий швидше пробиває шар, стабільніший)
- **Підпаски:** корея-бальза → [technique-rigging](technique-rigging.md)
- **Статус:** ✅ є (×3, куплені набором; раніше звані «#2»)

## Замітки
- ⚠️ Для делікатної мілини (~1 м, [Pod Dębem](waters-poddebem.md)) — **задуже**; там XM-02/03.
- Розмірний ряд набору (опції виробника): 1# (2.67 г, власна 1.35, 40.5 см) · **2# (2.91 г, є)** · 3# (3.13 г, власна 1.59, 41.5 см). Спільні антена/кіль.
- ⚠️ Розрізняти **власну вагу** (1.42 г) vs **вантажопідйомність** (2.91 г — число для підбору) → [gear-floats](gear-floats.md).
