# Mikado NSC Power Match 420

> ✅ робоча · основна котушкова снасть під короп/лин + херабуна-оснастка

## Короткий опис
- **Тип:** матчівка (кільця + котушка)
- **Довжина:** 420 см
- **Стрій / тест:** параболічний · 5–30 г
- **Ліміт ліски:** через котушку/фрикціон — не критичний (жила 0.255 / 7.95 кг ок)
- **Роль:** цілеспрямований короп/осетр + херабуна на ~2 м; відповідь на поломку [GOLDLITE](gear-rod-goldlite.md)
- **Статус:** ✅ у наявності · дебют 2026-07-06

## Замітки
- **Збір — spigot-з'єднання:** лишати **зазор ~1 см** (штатний, під знос); насаджувати щільно **з поворотом**, кільця **в лінію**. ⚠️ Зазор силою **НЕ виганяти**.
- **Парування:** котушка **Okuma Ceymar XT Match FD (CXT-30MS)** → [gear-reel-okuma](gear-reel-okuma.md).
- **Оснастка (07-06, херабуна ~2 м):** жила **Trabucco 0,255 (7,95 кг)** · секція **2.5 м** · поплавок **балса ~2.91 г** · повідець **Trabucco 0,203** (слабший за жилу) → [technique-rigging](technique-rigging.md), [gear-line](gear-line.md).
- ✅ **Розв'язка поломки маху:** котушка з фрикціоном **вибирає лісу** й **гасить ривок** замість бланку → 0,255 отримала законне місце (не на маху з лімітом #1.5). Балса 2.91 г — у межах касту 5–30 г.
- ❗ Робить план силового bat [TX3](gear-rod-tx3.md) **опційним**.
