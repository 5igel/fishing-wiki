# Kuter Port (Nieznanowice) — łowisko komercyjne (трофейний короп)

**Статус:** нове місце, **1 візит (2026-08-23), результат — нуль**. Комерційне трофейне łowisko з орієнтацією на великого коропа. Перший **фідерний** виїзд на дистанцію.

- **Адреса:** Marszowice 247, 32-420 Gdów (Nieznanowice).
- **Гео:** 49°54'26.4"N 20°15'16.4"E ≈ **49.907333, 20.254556** ([Google Maps](https://www.google.com/maps/search/?api=1&query=49.907333,20.254556)).
- **Від Кракова:** ~35 км.
- **Сайт:** https://kuterport.pl/ (ловисько: `/lowisko/`).
- **Позиціювання:** «pobić wędkarski rekord» — орієнтація на **великого коропа**.

## Режим / ціна
- Формат: **добові / денні стани** (наймання пега).
- Ціна стану, карта вендкарська / 1 гачок / C&R — **⏳ уточнити** (не з'ясовано).

## Стани (S1–S30)
- **S1–S8** — при домках (A1+…A8+), **пріоритет гостям домків**.
- **S9–S11** — денний найм.
- **S12–S30** — денний / добовий найм (category 2).
- **S20** — добовий найм (перевірений особисто, див. нижче).

## S20 — спостереження (2026-08-23)
- **Глибина / дно:** дно різне, у місці ловлі **мало мулу**.
- **Активність риби:** сплески переважно **далеко, від ~45 м і далі** (≈56 обертів шпулі @ 0,80 м/об).
- **Ключовий висновок:** активна риба стоїть **за межею пікерної дистанції** → потрібне **дистанційне фідерне вудлище (40–50 м)**, пікер не дотягується.
- Денний **поверхневий сплеск ≠ годівля з дна**.

## Ловля (2026-08-23) — S20, фідер, НУЛЬ
- **Час:** 11:00–23:00 (з перервами) + 06:00–08:00. **Результат: 0** (повний нуль).
- **Умови:** тепло, без спеки; риба сплескає, але переважно далеко (від ~45 м).
- **Снасть:** [Mikado Intro II Picker 270 / 40 г](gear-rod-mikado-picker.md); годівниця **20 г**; повідець **80 см** + гак **№14 (Kamasan B911)**; основа **0,203** ([gear-line](gear-line.md)). Котушка Daiwa TDR (запасна) діру не закриває — обмеження в **бланку**.
- **Прикормка:** Zanęta MatchPro Total FEEDER (Karp/Leszcz/Lin/Karaś), 1 кг + конопля + шоколад (той самий бренд).
- **Насадка:** кукурудза; далі через раз — пінка; іноді гнійовий черв'як.

**Хід сесії:**
1. Кукурудза, 20 обертів (~16 м) — 0
2. Додав пінку через раз, іноді черв'яка — 0
3. Зміна місця (краща брівка), активніше пінка + трохи в прикормку, 30 обертів (~24 м) — 0
4. Ранковий підхід на тому ж місці — 0

## Розбір (причина нуля) — геометрія, не тактика
- **Риба за межею подачі.** Активна риба від ~45 м (≈56 об.), максимальна подача — 30 об. (~24 м). Насадка лягала на ~20 м **ближче за найближчу активну рибу** → у порожню зону.
- **Пікер не дотягується.** Intro II Picker 270/40 г з годівницею 20 г + корм реально кидає ~20–25 м, макс ~30 м. **45 м фізично недосяжні** цим комплектом.
- **Шар.** Денний поверхневий сплеск ≠ годівля з дна; навіть при дотягуванні донна подача могла лягти **під** рибою.
- Друга котушка (Daiwa TDR) діру **НЕ** закриває — обмеження в бланку.
