# Гачки, вертлюги, фурнітура, інструменти

## Гачки
- ✅ **У наявності — готові повідці з гачками (усі Kamasan B911 X Eyed, з вушком):**

| Гачок | Повідцева жилка | Під що |
|---|---|---|
| №10, №12 | 0,181 мм (≈ #1.2) | більша риба (лящ/карась/короп акуратно) |
| №14, №16 | 0,162 мм (≈ #1.0) | дрібніша / делікатний клювок |

  - **Логіка:** більший гачок → товща жилка. Готові повідці міняються під розмір риби/клювок (напр. на [Бонарці 08-09](waters-bonarka.md) міняв №14 ↔ №12).
  - ⚠️ Нумерація **європейська** (більше число = менший гачок): №16 < №14 < №12 < №10.
  - Повідцева жилка — **Trabucco T-Force XPS Match Strong** (спеціальна повідцева серія): 0,162 та 0,181 мм → [gear-line](gear-line.md). Безбородість — B911 зазвичай безбородий, підтвердити під C&R.
  - ℹ️ Парк уніфіковано на **B911 X Eyed (№10–16)**. Раніше значились B911 Eyed №12 + DS911 Wide Gape №10 — ⏳ чи ще в ужитку.

## Вертлюги
- ⚠️ Дешеві штамповані = задирки на вушку «пиляють» ліску → були обриви
- Перевірені: Owner, Decoy, Gamakatsu (топ); VMC, Spro (середина)
- Розмір: rolling swivel #10–12
- Тест: вушком по нігтю (не дряпає), обертання без заїдань, на просвіт без шва
- **Вертлюг у підпаску (модульна система):** унизу підпаска — звичайний вертлюг під повідець + **силіконовий захист на вушко** (від збивання вузла). З'єднання підпаска з основною — **петля-в-петлю** (основна закінчується петлею), тож окремий **мікровертлюжок на основній НЕ потрібен** → [technique-rigging](technique-rigging.md).
  - ℹ️ Мікровертлюжки #20–24 (Mikado/Jaxon/Dragon; тест #20 ≈ 7–9 · #22 ≈ 5–7 · #24 ≈ 4–5 кг) — з першого плану модульної; на практиці заміщені кінцевою петлею. Лишаю як опцію → [shopping](shopping.md).

## Фурнітура
- ✅ **Krętlik Jaxon швидкозйом AC-356416 ×2** — конектор швидкої заміни всієї оснастки; зручно тримати кілька готових оснасток (легку/силову) і міняти на місці без перев'язування. Пасує до ідеї «друга силова оснастка» ([shopping](shopping.md)).
- Кембрики/стопори: силікон (не твердий ПВХ); Stonfo, Colmic — еталон
- **Повністю знімний тримач поплавця** — ключовий для модульної системи: дозволяє **зняти поплавець і змотати лінію без обрізання** (малі кільця Mikado). На основній лишаються тільки стопори → [technique-rigging](technique-rigging.md).
- **Силіконовий захист вертлюга** (у підпаску) — від збивання/защемлення вузла на вушку.
- **Розмір силіконових стопорів (space bean) — за діаметром ліски:** під наші ліски (#0.8–1.5 / 0.15–0.21 мм) = **S** (0.8–1.5 ). M/L зісковзують. Набір S/M/L хеджує маркування. У картці шукати таблицю «розмір→основна лінія/мм».
- Конектор на вершинку: ⚠️ вставні «wklejka do bata» (Stonfo) НЕ підходять — вершинки суцільний «китовий вус» ([gear-rods](gear-rods.md)). Потрібен тип під суцільний тонкий кінчик (петля/накидний), або те, що йде з вудкою.
  - **Конектор-подовжувач (барильце + PE-петля)** — з'єднання **петля-в-петлю** з основною лісою, фінішується стопором-силіконовий стопор проти заплутування. Повна інструкція в'язання (5 кроків, фото `raw/Sb07eba0a4d7b4956b1b0d3b6f4ef5c43w.avif` + `raw/S0eebbfec288c424ba1789a5edb051da98.avif`) → [technique-knots](technique-knots.md#конектор-подовжувач--вязання-петлі). Кандидат під суцільний китовий вус.
- Повідочниця (EVA foam board)

## Не економити на: лісці, гачку, вертлюзі. Можна простіше: кембрики, стопори.
