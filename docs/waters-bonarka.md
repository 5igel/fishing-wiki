# Озеро Бонарка

Локальне озеро (Краків, р-н Бонарка). Візити: **2026-08-09, 2026-08-10, 2026-08-11, 2026-08-14** (+ раніші виїзди, не записувались — Бонарка регулярна локація).

- **Режим:** **вільна вода PZW, але БЕЗ карти вендкарської** — оплата денна **35 zł**. Години **6:00–21:00**. **1 гачок**, **catch & release**.
  - ✅ PZW-вода з **денною оплатою без карти** вендкарської (як і [Kłaj](waters-klaj.md) — обидва доступні без карти, лише дозвіл).
  - Узгоджується з профілем: 1 гачок, C&R → готові повідці з 1 гачком ([gear-terminal](gear-terminal.md)).
- ⏳ **Гео / глибина / дистанція** — уточнити з практики. **Риба:** лящ/підлящ (домінують) + краснопірка + карась (див. сесії нижче).

## Ловля (2026-08-09) — ранок, лящ

- **Погода:** вітер (→ важчий поплавок).
- **Снасть:** [Rongyu 5.7 хера](gear-rod-rongyu-570.md); поплавок [балса 2.91 г](gear-float-balsa.md) (через вітер); гачки **№14 і №12** (міняв по ходу).
- **Улов:** **2 лящі ~40 см ≈ ~1.0–1.3 кг** (`raw/DBAA4715-9D99-4CAE-BA35-3FF173BC846F.jpg`) + **~6 підлящів 25–30 см ≈ ~0.3–0.5 кг**. Деталі/вага → [fish-log](fish-log.md).
- ✅ Робочий ранковий вихід по лящу на хера-снасть; вітер закрила балса.
