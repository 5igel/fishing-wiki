# Озеро Бонарка

Локальне озеро (Краків, р-н Бонарка). Візити: **2026-08-09, 2026-08-10, 2026-08-11, 2026-08-14, 2026-08-18, 2026-08-19** (+ раніші виїзди, не записувались — Бонарка регулярна локація).

- **Режим:** **вільна вода PZW, але БЕЗ карти вендкарської** — оплата денна **35 zł**. Години **6:00–21:00**. **1 гачок**, **catch & release**.
  - ✅ PZW-вода з **денною оплатою без карти** вендкарської (як і [Kłaj](waters-klaj.md) — обидва доступні без карти, лише дозвіл).
  - Узгоджується з профілем: 1 гачок, C&R → готові повідці з 1 гачком ([gear-terminal](gear-terminal.md)).
- ⏳ **Гео / глибина / дистанція** — уточнити з практики. **Риба:** лящ/підлящ (домінують) + **густера** + краснопірка + карась + **короп** (зловлено 08-18/08-19; раніше 2 зійшли 08-14) — див. сесії нижче.
