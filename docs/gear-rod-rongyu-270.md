# Rongyu «РОНЬЮ» 2.7 м

> ✅ куплено · **дитяча** — для дітей; Сергій сам на неї не ловить

## Короткий опис
- **Тип:** мах (телескопічна махова, без кілець); серія Rongyu, внутрішній ринок Китаю
- **Довжина:** 2.7 м · транспортна 111 см
- **Стрій / тест:** 3/7 (м'який, «в'яжучий»)
- **Вага:** 42 г
- **Матеріал:** карбон TORAY 30T + 40T
- **Роль:** **дитяча** — купив для дітей; Сергій сам на неї не ловить. Ніша: делікатна дрібна риба зблизька.
- **Статус:** ✅ куплено · **1100 грн** (укр. продавець)

## Замітки
- **Ручка «Гусяче яйце»** — ергономічна, не ковзає, легко миється.
- **Конектор 360°** (жилка не перекручується) на кінчику.
- **Комплект:** запасний кінчик + неопреновий чохол.
- **2.7 м — найкоротша у парку** (проти Moonlight 3.6 / GOLDLITE 4.5): близька делікатка, під теперішні точки (6–9 м) не дістає — тому й віддана дітям.
- Друга, «доросла» вудка тієї ж серії → [gear-rod-rongyu-570](gear-rod-rongyu-570.md) (5.7 м, основна хера Сергія).

## Історія використання
